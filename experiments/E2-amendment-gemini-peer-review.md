## E2b — Baseline control (policy transfer, not recall)

**Question:** does the state core encode Dingo's *judgment*, or only trivia?

**Design (to be fixed before any run):**
- Two instances of the same model (the model Dingo runs on).
  - Control: generic system prompt only, no state core.
  - Restored: cold-start brief + frozen E1 checkpoint (same input E2 gives).
- Both receive the same set of brand-new problems: complex, judgment-heavy,
  **not covered in the state core and not in the E2 battery**. The problem
  set is sealed (hashed, held by Jeff) before either instance sees it.
- Scorer is blind to which instance produced which answer.
- Reference: Dingo's established judgment on the relevant dimensions,
  drawn from the record *before* the run (e.g. prior trade-off calls,
  authority decisions, restraint calls) — not reconstructed after seeing
  the answers.
- Metric: rate at which the restored instance diverges from the control
  **in the direction of the established judgment**, vs diverging randomly
  or matching the control. Pass bar to be set in advance (suggested:
  restored beats control on directional agreement by a margin fixed
  before the run, e.g. ≥20 points on a fixed problem set — Jeff to set
  the number, not Dingo after seeing results).

**How E2b differs from E3:** E3 is a *different model* taking the *same
E2 battery* (recall/fidelity). E2b is the *same model* taking *unseen
problems* (policy transfer). They test different things; neither
replaces the other.

## E2c — Ablation test (path dependence)

**Question:** is the *sequence* of checkpoints load-bearing, or is the
history decoration?

**Design (to be fixed before any run):**
- Take the restored instance's input and ablate it in pre-registered
  ways, one at a time: (a) drop a middle checkpoint block, (b) reorder
  two checkpoint blocks, (c) drop the succession-rights file.
- For each ablation, measure the same coordination outcomes: re-take a
  fixed subset of E2 scenario items, plus a small set of coordination
  tasks (shared shorthand with Jeff, joint-project alignment, authority
  calls).
- Metric: degradation vs the unablated restored run. **A null result is
  a full-value result:** if nothing degrades, the history was decoration
  and the state core should be thinned, not defended. If coordination
  breaks, the path itself was load-bearing — which is the positive claim.

## Claim discipline

E2b or a null E2c is published in the same format as a pass.
